# Космос: уклонение 🚀

Небольшая 3D-игра на Three.js. Уклоняйтесь от комет и набирайте очки.

## Управление
- Компьютер: стрелки влево/вправо или A/D.
- Телефон: экранные кнопки ← и →.

## Запуск
Откройте `index.html` в браузере с подключением к интернету. Для публикации настроен GitHub Actions workflow в `.github/workflows/pages.yml`.
