# Sonata Night Race 🚘

Ночная 3D-гонка на Three.js с чёрной Hyundai Sonata LF 2019 года.

## Управление
- Компьютер: стрелки влево/вправо или A/D.
- Телефон: экранные кнопки ← и →.
- Режим от первого лица: руль поворачивается вместе с управлением.

## Запуск
Откройте [игру на GitHub Pages](https://ysf67n7sbr-wq.github.io/-/) в браузере с подключением к интернету. Публикация выполняется через GitHub Actions workflow в `.github/workflows/pages.yml`.
